# TaskBot Voice — Numbered To-Do & Timer Chatbot

A single-page voice-over and text chatbot to-do list with live countdown timers and Web Audio API alarms.

## Deploy to Vercel

### Option 1: Via GitHub (Recommended)
1. Upload `index.html` and `vercel.json` to a new GitHub repository.
2. Go to https://vercel.com/new and import your repository.
3. Leave Framework Preset as **Other** and click **Deploy**.

### Option 2: Via Vercel CLI
Run `npx vercel` inside this folder and follow the prompts, or run `npx vercel --prod` to deploy directly to production.
